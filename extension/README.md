# 🏮 Lantern Chrome Extension — Setup Guide

> **Automated WCAG 2.1 Web Accessibility Auditing for Developers**

---

## 🚀 Quick Setup Instructions

Follow these steps to install and run the Lantern Chrome Extension:

### Step 1: Extract the ZIP
Unzip the downloaded `lantern-extension.zip` file to a folder on your computer.

### Step 2: Open Extensions in Chrome
Open Google Chrome and navigate to:
```text
chrome://extensions
```
*(In Microsoft Edge, navigate to `edge://extensions`)*

### Step 3: Enable Developer Mode
In the **top-right corner** of the page, toggle the **"Developer mode"** switch to **ON**.

### Step 4: Load Unpacked
1. Click the **"Load unpacked"** button in the **top-left corner**.
2. Select the extracted `lantern-extension` folder (the folder containing `manifest.json`).
3. Click **Select Folder** (or **Open**).

### Step 5: Pin and Start Auditing
1. Click the **puzzle piece icon** (🧩) next to your browser address bar.
2. Click the **Pin icon** (📌) next to **Lantern** to keep it in your toolbar.
3. Open any webpage, click the **Lantern** icon in your toolbar, and click **"Audit This Page"**!

## ✨ Features

- **Live In-Browser DOM Scanning**: Scans the rendered DOM for image alt text, heading hierarchy, form labels, and color contrast.
- **In-Page Visual Highlights**: Draw highlight boxes and tags directly on elements violating WCAG rules.
- **WAVE-Style Document Linearization**: Disable CSS to test raw document flow and screen reader reading order.
- **Code Fix Generator**: Generates instant copy-paste code patches.
- **Live Sync**: Sync reports directly to the web dashboard.
