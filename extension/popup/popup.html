    WCAG Disclaimer & Manual Testing Guide

    Automated tools catch only a subset of accessibility barriers. Essential manual checks:

    • Keyboard Tab Test: Press Tab to ensure all interactive elements receive visible focus and are operable without a mouse.
    • Screen Reader: Test with VoiceOver (Cmd + F5 on macOS) or NVDA on Windows.
    • 200% Zoom: Zoom browser to 200% to ensure layout reflows without overlapping content.
